# Plan: `ast_grep_map` — aider-style code map with PageRank

## Goal
Add a new opencode tool `ast_grep_map` that produces an **aider-style repo map**
(real source lines under `│`/`⋮` box-drawing, ranked by **PageRank**) and
**persists the PageRank graph to disk as JSON**. Faithful port of aider's
`repomap.py` algorithm, using **tree-sitter** + aider's verbatim `.scm` query
files for symbol def/ref extraction.

## Locked decisions (from user)
1. **Symbol extraction = tree-sitter** + aider's `-tags.scm` queries (faithful
   port). New npm deps in the workspace `.opencode/node_modules`.
2. **Scope model:** `paths`/`globs` choose which files appear in the OUTPUT map;
   the PageRank graph is built from ALL code files in the worktree so rankings
   reflect real importance (aider behavior).
3. **Persistence:** graph JSON written to project-local `<worktree>/.ast-grep/`
   (diff/debug friendly); env override `OP_AST_GREP_MAP_DIR`.

## Deliverable (3 new files + vendored queries + deps)
Mirrors the existing ast-grep plugin's **2-file shim+impl pattern** (required
because opencode's loader throws on non-function named exports in scanned
`plugins/*.ts` files — see `.opencode/plugins/ast-grep.ts:1-12`).

| Path | Role |
|---|---|
| `.opencode/plugins/ast-grep-map.ts` | 12-line entry shim; `import X from "../ast-grep-map-impl.ts"; export default X` |
| `.opencode/ast-grep-map-impl.ts` | Full implementation (NOT scanned by opencode) |
| `.opencode/ast-grep-map-tests/smoke.ts` | Smoke + convergence tests (mirrors `ast-grep-tests/`) |
| `.opencode/queries/*.scm` | Vendored aider query files (TS, TSX, JS, Python, Go, Rust, C++) |
| `.opencode/package.json` | Add tree-sitter deps |
| `.opencode/tsconfig.json` | Add `ast-grep-map-impl.ts` + `plugins/ast-grep-map.ts` to `include` |

## A. Dependencies & installation
Add to `.opencode/package.json` `dependencies` (workspace-level, which is where
the plugin resolves `node_modules`; matches the existing `@opencode-ai/plugin`
location):
```json
"tree-sitter": "^0.25.0",
"tree-sitter-typescript": "^0.23.2",
"tree-sitter-javascript": "^0.25.0",
"tree-sitter-python": "^0.25.0",
"tree-sitter-go": "^0.25.0",
"tree-sitter-rust": "^0.24.0",
"tree-sitter-cpp": "^0.23.4"
```
Install: `npm install --prefix .opencode <pkgs>` (writes `.opencode/package-lock.json`).

**ESM import (no bundler):** tree-sitter packages are CommonJS. Use
`createRequire` to load them robustly from the ESM impl file:
```ts
import { createRequire } from "node:module"
const require = createRequire(import.meta.url)
const Parser = require("tree-sitter")            // default export is the class
const TS = require("tree-sitter-typescript")     // { typescript, tsx }
const JS = require("tree-sitter-javascript")     // { javascript } (newer) — verify at runtime
```
**Prebuilt binaries:** `tree-sitter` ships `prebuild-install` artifacts for
linux-x64/darwin-(arm64,x64)/win32; the grammar packages do too. Node 22 ABI
(linux-x64 confirmed present) is covered. If a prebuilt is missing, `node-gyp`
falls back to source build (needs python3 + C++ — not guaranteed here; treat a
load failure for a grammar as "language unsupported", warn, and skip).

**Query API contract** (from `tree-sitter.d.ts`):
```ts
new Parser.Query(language, scmSource).captures(tree.rootNode)
  → Array<{ name: string; node: { text: string; startPosition: {row,column}; ... } }>
```
`Parser`/`Language` cached lazily per language in a `Map`.

## B. Vendored `.scm` queries (`.opencode/queries/`)
Copy verbatim from `Aider-AI/aider/aider/queries/tree-sitter-languages/`:
- `typescript-tags.scm` (also used for `.tsx` — note aider has no language-pack
  TS query, so this file covers both; load via the `tsx` grammar for `.tsx`)
- `javascript-tags.scm` — **strip Helix-only directives** (`#strip!`,
  `#select-adjacent!`, `#set-adjacent!`) which core tree-sitter rejects; aider
  ignores the `@doc` capture anyway so this is safe. Keep `#not-match?`/`#eq?`.
- `python-tags.scm`, `go-tags.scm`, `rust-tags.scm`, `cpp-tags.scm` (clean, no
  exotic directives)
Loader: `loadQuery(lang): string` reads + caches file text by canonical lang.

## C. Module structure of `ast-grep-map-impl.ts`
(sections in order; one-line purpose each)

1. **Imports** — `node:` builtins (`fs`/`fs/promises`, `path`, `crypto`,
   `child_process` only if needed, `module.createRequire`); `createRequire` for
   tree-sitter; `{ tool, type Plugin, type ToolContext } from "@opencode-ai/plugin"`.
   Reuse from sibling: `import { runtimeTargetDir } from "./ast-grep-impl.ts"`
   **only if useful** (we don't need the sg binary — pure tree-sitter — so likely
   no cross-import; keep impl standalone to avoid coupling).
2. **Constants**
   - `LANG_EXT` — extension → canonical lang map (TS/TSX/JS/Py/Go/Rust/C++ subset;
     subset of ast-grep-impl's `LANGUAGES`).
   - Defaults: `DAMPING=0.85`, `MAX_ITER=100`, `TOL=1e-6`, `DEFAULT_MAX_TOKENS=1024`,
     `LINE_TRUNC=100`, `CHARS_PER_TOKEN=4`, `MAP_MUL_NO_FILES=8`.
   - `MAP_DIR_ENV="OP_AST_GREP_MAP_DIR"`.
3. **`languageForFile(fname): string | null`** — ext → canonical lang.
4. **`loadQuery(lang): string | null`** — read vendored `.scm`, cached.
5. **`getParser(lang): {parser, language} | null`** — lazy, cached; returns null
   on load failure (warns once).
6. **`getTags(fname, relFname): Tag[]`** (mtime-cached via `Map<fname,{mtime,tags}>`):
   parse → `query.captures(root)` → emit def/ref tags; **reference backfill**: if
   file has defs but no refs, tokenize identifiers via `/\b[A-Za-z_$][\w$]*\b/g`
   and emit each as a `ref` (divergence from aider's Pygments — documented).
   - `interface Tag { rel_fname: string; fname: string; line: number; name: string; kind: "def"|"ref" }`
7. **Graph types**
   ```ts
   interface GraphEdge { src: string; dst: string; weight: number; ident: string }
   interface Graph {
     nodes: string[]                  // rel_fname list
     edges: GraphEdge[]               // referencer(src)→definer(dst), parallel edges kept
     outWeight: Map<string, number>   // per-src sum (for rank distribution)
   }
   ```
8. **`buildGraph(defines, references, mentionedIdents, chatFiles): Graph`** —
   verbatim aider heuristics:
   - `mul` starts 1.0; `mentionedIdents` ×10; `(snake|kebab|camel) && len>=8` ×10;
     `startsWith("_")` ×0.1; `defines[ident].size > 5` ×0.1.
   - per `(referencer, numRefs)` in `Counter(references[ident])`:
     `weight = mul * sqrt(numRefs)`; push edge. (chat-file ×50 boost is personalization's
     job here, not edge weight — keep faithful: aider applies chat boost in BOTH
     personalization and a `use_mul *= 50` when `referencer in chat_rel_fnames`.
     Reproduce the edge-level ×50 too.)
   - definer with zero refs → self-edge weight 0.1.
   - if no references repo-wide → `references = defines`.
9. **`pageRank(graph, personalization, {alpha, max_iter, tol}): Map<node, number>`**
   — pure-TS power iteration. **Precise math:**
   - Aggregate parallel edges into `adj[u] = Map<v, sumWeight>` (networkx
     MultiDiGraph pagerank sums multi-edge weights).
   - Build `outDeg[u] = Σ adj[u][*]`; dangling = nodes with outDeg 0.
   - Normalize personalization `p` so `Σ p = 1` (if empty/unnormalizable → uniform).
   - Init `r[u] = 1/N`.
   - Iterate up to `max_iter`: `new[u] = (1-alpha)*p[u] + alpha * ( Σ_{v→u} r[v]*w(v,u)/outDeg[v] ) + (1-alpha) * danglingMass * p[u]`
     where `danglingMass = Σ_{dangling v} r[v]` and the `(1-alpha)` share of dangling
     is redistributed via `p` (networkx: dangling redistributed through
     personalization; the teleport term is `(1-alpha)*p[u]` and dangling handled as
     `(1-alpha) * danglingMass * p[u]`). **Verify the exact networkx formula during
     implementation** — capture it in a comment with a link. Convergence: L1
     `Σ|new-r| < tol`. On `ZeroDivisionError`-equivalent (all-zero / N=0) →
     return empty.
10. **`rankDefinitions(graph, scores, mentionedIdents): RankedTag[]`** — distribute
    each src's rank across out-edges by weight share → accumulate
    `(dst, ident) → rank`; sort desc by `(rank, key)`; resolve to def `Tag`s.
11. **`tokenCount(text): number`** — `Math.ceil(text.length / CHARS_PER_TOKEN)`
    (divergence: no model tokenizer; documented).
12. **`renderTree(tags, chatFiles): string`** — the `│`/`⋮` renderer:
    - sort tags by `(rel_fname, line)`.
    - per file: header `<rel>:\n`; for each def line + ancestor-scope lines
      (enclosing class/struct/fn header via tree-sitter `node.parent` walk until a
      named def ancestor) prefix `│`; collapse hidden runs to a single `⋮`.
    - hard-truncate each line to `LINE_TRUNC`.
    - Use `mark_lois=false` semantics → uniform `│` (no `█`).
13. **`binarySearchTokenBudget(rankedTags, maxTokens, render): string`** — aider's
    search: init `middle = min(⌊maxTokens/25⌋, N)`; accept if within budget AND
    larger than best; early-stop within 15% (`ok_err=0.15`).
14. **`discoverCodeFiles(worktree, langFilter?): string[]`** — recursive walk;
    skip `node_modules`, `.git`, `.ast-grep`, `dist`, `build`, build artifacts;
    respect `.gitignore` if cheap (else hard-coded ignore list). Extension filter
    via `LANG_EXT`.
15. **`resolveMapDir(worktree): string`** — `process.env[MAP_DIR_ENV]` (if set &
    usable) else `join(worktree, ".ast-grep")`; `mkdir -p`.
16. **`persistGraph(graph, scores, rankedTags, mapDir, meta): string`** — write
    `.ast-grep/graph.json` atomically (tmp + rename). Schema in §E.
17. **`ast_grep_map` tool definition** — see §D.
18. **`export const tools = { ast_grep_map }`** + **`export default (async () =>
    ({ tool: tools })) satisfies Plugin`** (no `event` hook needed — no binary to
    provision).

## D. The `ast_grep_map` tool signature
```ts
args: {
  paths:        tool.schema.array(tool.schema.string()).optional()
                  .describe("Files/dirs to include in the OUTPUT map (default: worktree root)."),
  globs:        tool.schema.array(tool.schema.string()).optional()
                  .describe("Include/exclude globs for OUTPUT map files (prefix '!' to exclude)."),
  lang:         tool.schema.string().optional()
                  .describe("Restrict to one language (ts, js, py, go, rs, cpp)."),
  max_tokens:   tool.schema.number().optional()
                  .describe("Token budget for the rendered map (default 1024)."),
  mentioned_idents: tool.schema.array(tool.schema.string()).optional()
                  .describe("Symbols to boost in ranking (aider 'mentioned_idents')."),
  refresh:      tool.schema.enum(["auto","always"]).optional()
                  .describe("auto=reuse cached graph if sources unchanged; always=rebuild."),
  json:         tool.schema.boolean().optional()
                  .describe("Return the persisted graph JSON instead of the rendered map."),
}
```
**`execute(args, ctx)` flow:**
1. `worktree = ctx.worktree || ctx.directory`; `scopeFiles = matchScope(worktree, args.paths, args.globs, args.lang)` (the OUTPUT set; default = everything).
2. `allFiles = discoverCodeFiles(worktree, args.lang)` (graph set).
3. For each file → `getTags`; aggregate `defines[name] = Set<file>`, `references[name] = file[]` (unless `refresh==="auto"` AND graph.json mtime-cache valid → load persisted ranked tags, skip to step 8).
4. `mentionedIdents = new Set(args.mentioned_idents ?? [])`; `chatFiles = new Set(scopeFiles)`.
5. `graph = buildGraph(...)`; `p = personalization(chatFiles, allFiles, mentionedIdents)`.
6. `scores = pageRank(graph, p, {alpha:DAMPING,max_iter:MAX_ITER,tol:TOL})`.
7. `ranked = rankDefinitions(graph, scores, mentionedIdents)`.
8. `out = persistGraph(graph, scores, ranked, resolveMapDir(worktree), {...})`.
9. `map = binarySearchTokenBudget(ranked.filter(not-in-chatFiles), args.max_tokens ?? DEFAULT_MAX_TOKENS, renderTree)`; if empty chat/scope, multiply budget by `MAP_MUL_NO_FILES`.
10. Return: `args.json ? readGraphJson : "<map>\n\n— mapped N of M files; graph persisted to <path>"`.

## E. Persistence JSON schema (`.ast-grep/graph.json`)
```jsonc
{
  "version": 1,
  "worktree": "/abs/path",
  "generatedAt": "2026-06-20T..Z",
  "damping": 0.85, "maxIter": 100, "tol": 1e-6,
  "nodeCount": 42, "edgeCount": 318,
  "nodes": ["rel/path/a.ts", "rel/path/b.ts"],
  "edges": [ { "src": "rel/a.ts", "dst": "rel/b.ts", "weight": 3.16, "ident": "myFunc" } ],
  "scores": { "rel/a.ts": 0.0821, "rel/b.ts": 0.0417 },
  "rankedSymbols": [ { "file": "rel/b.ts", "ident": "myFunc", "rank": 0.0234, "line": 12 } ],
  "mentionedIdents": ["myFunc"],
  "sourceMtimes": { "rel/a.ts": 1718870000 }
}
```
`sourceMtimes` powers `refresh:"auto"` cache validity (rebuild if any changed).

## F. Faithful-port checklist / divergences
**MUST match aider:** graph = files-as-nodes MultiDiGraph; edge weight heuristics
(×10/×10/×0.1/×0.1, sqrt refs, chat ×50, self-edge 0.1); PageRank α=0.85/100/1e-6
with personalization + dangling; rank distribution to `(file,ident)`; binary-search
token budget (ok_err=0.15, init tokens//25); render format (`│` lines, `⋮` gaps,
`path:` header, 100-char truncation, `mark_lois=false`).
**Intentional divergences (documented):**
- **Token counting:** `len/4` proxy vs real tokenizer (no model access in plugin).
- **Reference backfill:** regex identifier tokenizer vs Pygments (no Pygments in Node).
- **JS `.scm`:** Helix-only predicates stripped (aider ignores `@doc` anyway).
- **No `map_mul_no_files` context-window cap** (we don't know context size; use fixed ×8).
- **Parent-scope context** via tree-sitter `node.parent` walk (aider uses grep_ast TreeContext; we approximate with AST ancestry — faithful enough).

4. **Convergence sanity:** PageRank `Σ scores ≈ 1.0` (±1e-4); deterministic across runs.
5. **Persistence:** `.ast-grep/graph.json` written, re-parseable, `nodeCount>0`, `edgeCount>0`; `refresh:"auto"` skips rebuild when mtimes unchanged.
6. **Whole-repo graph:** run with no `paths` → graph nodes include files NOT in the output map (confirms graph-from-whole-repo semantics).
7. **Plugin load:** restart opencode / run `/doctor` → no "Plugin export is not a function" error (shim exports only default).

## H. Risk register
1. **tree-sitter native load failure** on target ABI → mitigation: `getParser`
   catches `require` throw, warns, marks lang unsupported; tool degrades to
   langs that loaded. Verify prebuilt present at install time (step G.1).
2. **PageRank multigraph correctness** → mitigation: aggregate parallel edges
   into `adj[u][v]` before iteration; unit-test `Σ scores ≈ 1`; add a tiny
   synthetic graph (3 nodes, known ranks) assertion.
3. **Parent-scope rendering via tree-sitter ancestry** → mitigation: walk
   `node.parent` until a `name.definition.*`-capturable ancestor; if none, just
   show the def line (still readable).
4. **Large-repo performance** (O(files × avg tags)) → mitigation: mtime cache on
   `getTags`; cap walked files; `refresh:"auto"` default. Document a soft limit.
5. **opencode loader export rule** → mitigation: keep ALL named exports in
   `ast-grep-map-impl.ts`; shim re-exports default only (proven pattern).
